## Problem

## Scope

## Acceptance criteria
- CLI oficial actualizado mediante mecanismo autorizado, o bloqueo explícito si no ofrece el enforcement requerido. Nada de bypass o fallback a API.
- Sesión de suscripción permanece en cliente oficial del host; backend/Docker/DB/logs no reciben sus tokens, HOME ni API keys. Secreto propio del puente distinto de la suscripción.
- Consulta manual de un permalink Slack concreto; backend no visita URLs y no mezcla datos reales con provider fixture. Sin perfil de lectura aprobado, no ejecutar herramientas.
- PreToolUse de denegación por defecto: solo herramienta exacta del perfil y argumentos limitados al hilo autorizado; cualquier fallo del control bloquea. Prompt y allowedTools no bastan como política.
- Runs UUID con idempotencia, claim/lease/fencing, cancelación, plazo y resultado validado. No relanzar consultas externas automáticamente tras perder lease. No transacción DB abierta durante CLI/red.
- Supervisor con argv fijo, sin shell, entorno permitido sin API keys/proveedores alternativos, límites de tiempo/salida/turnos y terminación de su grupo de procesos.
- Panel distingue demo, consulta real, configuración pendiente, ejecución, error y propuesta no validada. No publicar, cerrar ni crear tareas automáticamente.
